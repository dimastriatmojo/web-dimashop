# GurunaStore - Toko Online Vanilla HTML/CSS/JavaScript

## Fitur
- Tampilan toko mengikuti referensi gambar.
- Kategori, ukuran, warna, pencarian, dan sorting.
- Keranjang belanja.
- Tambah/kurangi jumlah barang dan hapus dari keranjang.
- Checkout.
- Input nama, nomor telepon, alamat lengkap, kota, kode pos.
- Pilihan pembayaran (simulasi): COD, transfer bank, e-wallet.
- Pesanan tersimpan di localStorage dan dapat dilihat di menu Pesanan.
- Stok otomatis berkurang setelah pesanan dibuat.
- Admin dapat posting produk.
- Admin dapat memasukkan URL gambar atau upload gambar.
- Admin dapat menghapus produk.
- Responsive untuk desktop dan HP.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Tidak perlu XAMPP untuk demo frontend ini.

## Penting untuk penggunaan nyata
Versi ini menyimpan data di `localStorage`, sehingga data hanya ada di browser/perangkat tersebut.
Untuk toko online sungguhan dengan banyak pembeli, perlu backend + database + autentikasi admin + API + payment gateway + sistem ongkir.

Struktur:
- index.html
- style.css
- app.js
